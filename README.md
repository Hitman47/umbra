# Umbra

App Android perso (téléphone / tablette) pour lire les vidéos d'un NAS, chez soi ou à distance via Tailscale.

- Lecteur intégré basé sur libmpv : 4K HDR, Dolby Vision, DTS / TrueHD, sous-titres ASS / PGS.
- Accès au NAS en SMB (NFS en option) via un mini-serveur HTTP local.
- Phase 2 : bibliothèque style Infuse avec métadonnées TMDB.
- Phase 3 : suivi Trakt.
